# App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Pedal Pay's installable app: first-run setup, the morning prompt, and the main screen with numbers and a month calendar.

**Architecture:** A static site with no build step, served as-is by GitHub Pages. Logic lives in small ES modules under `src/` that take plain data and return plain data, so Node can test them without a browser. `src/app.js` is the only module that touches the DOM, `localStorage` and notifications. A service worker and a web manifest make the site installable in Edge.

**Tech Stack:** HTML, CSS and JavaScript ES modules; Node 22's built-in `node:test` for unit tests; Playwright (already installed, `require('playwright')`) for one browser test. No npm dependencies.

**Spec:** `docs/roadmap/app.md`, bound by `docs/adr/storage.md`, `docs/adr/morning-prompt.md`, `docs/adr/hosting.md` and `docs/adr/look.md`. Words follow `CONTEXT.md`.

## Global Constraints

- No build step and no runtime dependencies. Every file is served exactly as written.
- All paths in HTML, the manifest and the service worker are relative (`./`), since GitHub Pages serves the site under `/pedal-pay/`.
- Interface text is English and uses the glossary words: ride, morning prompt, km per ride, rate per km, streak.
- Colours (from `docs/adr/look.md`). Light: brand `#D4471F`, sun `#FFC93C`, paper `#FFF8F3`. Dark (follows `prefers-color-scheme`): background `#151B2E`, surface `#1E2640`, brand `#FF8A4C`, sun `#FFC93C`.
- Font: Fredoka from Google Fonts with fallback `system-ui, sans-serif`.
- Logo: a yellow (`#FFC93C`) bike whose front wheel is a coin, on a brick-orange (`#D4471F`) rounded tile, vertically centred.
- Dates are local calendar days keyed as `YYYY-MM-DD`. Never use `toISOString()` for a key.
- Storage key `pedal-pay`. The fill bookmark entry will read this shape, so it is versioned.

## Review Focus

1. **The app stays open overnight.** People never close it. On `visibilitychange` back to visible, the app recomputes today and shows the morning prompt if today now needs one. Covered in Task 6's browser test.
2. **Browser storage is empty, blocked or corrupt.** A private window, wiped data or hand-edited JSON must give the first-run setup, not a blank page. Covered in Task 2.
3. **A Belgian user types `0,36`.** Comma decimals in km per ride and rate per km are accepted. Covered in Task 2.
4. **Local midnight and daylight-saving days.** A ride at 00:30 on 29 March 2026 lands on 29 March. Covered in Task 1.
5. **Notifications are refused.** The prompt window must still work and nothing may throw. Covered in Task 6.

### Task 5: Wiring the views

**Files:**
- Create: `src/app.js`

**Interfaces:**
- Consumes:
  - all of Tasks 1–3
  - the element ids from Task 4
- Produces:
  - `window.pedalPay = { today(): string }`, a seam the browser test overrides through `localStorage['pedal-pay-today']` when present. It is read only when that key exists.
  - a message listener for `{ type: 'answer', ride: boolean }` from the service worker.

- [ ] **Step 1: Implement `src/app.js`.**

On load:
1. Load the state.
2. If it is not set up, show `#setup`.
3. Otherwise, if `needsPrompt`, show `#prompt` and call `notify()` (Task 6).
4. Otherwise, show `#main`.

The views behave as follows:
- **Setup and settings:** both use `parseDecimal`. An invalid field gets `aria-invalid="true"` and the message "Enter a number above 0, like 18 or 0,36"; nothing is saved.
- **Prompt:** Yes or No calls `setAnswer` and saves, shows `#prompt-saved` for 1.2 s, then shows `#main`.
- **Main:**
  - The scope switch picks month or year totals; month is the default.
  - `#stat-streak` reads `🔥 N-day streak`. It is hidden when N is 0.
  - The calendar shows the selected month, with a month offset reached through prev and next across year boundaries.
  - Clicking a past or present day flips it between ride and no ride. Future days are disabled buttons.
- **Waking up:** on `visibilitychange` to visible, recompute today and re-run the start-up choice.
