# Morning prompt

The app is installed from Edge and set to start at Windows sign-in. When it
starts on a workday without an answer, it shows a small window with Yes and
No and also sends a notification, in case the window opens behind others. A
browser app cannot reliably wake itself at a set time, so sign-in is the
moment it asks.

A missed day counts as no ride. The user can still mark it in the app's month
calendar, where weekends and Belgian public holidays are greyed out.
