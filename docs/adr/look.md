# Look

The logo is a yellow bike whose front wheel is a coin, on a brick-orange tile.
Light mode uses brick orange #D4471F, sun yellow #FFC93C and paper #FFF8F3.
Dark mode follows the system setting and uses night navy #151B2E with orange
#FF8A4C and the same yellow; a near-black background was rejected because it
looked like a calculator. Type is Fredoka, rounded to match the friendly tone.
Calendar days are circles.
